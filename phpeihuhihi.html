    3.5. 类型变化

    PHP 中的变量没有固定类型。该类型可能会在运行过程中根据变量的赋值而改变。在涉及多种类型数据的运算中，PHP 解释器会进行隐式转换，将操作数转换为一种通用类型。 如果开发人员不了解这些隐式转换，它们可能会成为难以发现的错误源。下面是一个展示隐式和显式转换的 [bases-04.php] 脚本：

    
<?php

// 参数传递中采用严格类型
declare(strict_types=1);

// 隐式类型转换
// 类型 --> bool
print "Conversion vers un booléen------------------------------\n";
showBool("abcd", "abcd");
showBool("", "");
showBool("[1, 2, 3]", [1, 2, 3]);
showBool("[]", []);
showBool("NULL", NULL);
showBool("0.0", 0.0);
showBool("0", 0);
showBool("4.6", 4.6);

function showBool(string $prefixe, $var) : void {
  print "(bool) $prefixe : ";
  // 在随后的测试中，$var 会自动转换为布尔值
  if ($var) {
    print "true";
  } else {
    print "false";
  }
  print "\n";
}

    注释

    • 第 4 行：要求在指定函数参数时进行严格的类型检查；
    • 第 18 行：函数 [showBool] 的目的是展示当需要将任意类型的值转换为布尔值（第 21 行）时，解释器 PHP 执行的隐式（自动）转换；
    • 第 18 行：参数 $var 未指定类型。因此，实际参数可以是任何类型。而参数 $prefixe 必须为字符串类型。函数 showBool 不返回任何值（void）；
    • 第21行：在if($var)语句中，$var的值必须转换为布尔值，才能对if进行求值。 令人惊讶的是，解释器 PHP 对于给定的任何类型的值都能给出响应；
    • 第9-16行：函数[showBool]的参数值将依次为：
      • 第 9 行：非空字符串：结果为 TRUE（区分大小写，TRUE=true）；
      • 第 10 行：一个空字符串：结果为 FALSE；
      • 第 11 行：一个非空数组：结果为 TRUE；
      • 第 12 行：一个空数组：结果为 FALSE；
      • 第 14 行：实数 0：结果 FALSE；
      • 第 15 行：整数 0：结果 FALSE；
      • 第 16 行：不为 0 的实数（或整数）：结果 TRUE；
