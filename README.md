本项目提供了一系列 PHP 7 控制台脚本，旨在展示该语言及其生态系统的各个方面。

## 仓库内容

示例涵盖以下主题：
- **语言结构**
- **文件访问**
- **数据库访问**
- **互联网访问**

## Web 编程方法论

此处从 **Web 服务** 的角度探讨 Web 编程。在此语境下，我们将“Web 服务”定义为生成纯文本的任何应用程序（数据服务器），与生成 HTML、CSS 和 JavaScript 混合内容的网页服务器相对。

### 涉及的关键概念
本项目探讨了传统编程中使用的基本Web概念：
- HTTP协议
- JSON或XML响应格式
- 会话管理
- 身份验证
