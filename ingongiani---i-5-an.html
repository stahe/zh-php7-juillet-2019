    13.3.2.1. 基类 [BaseEntity]

    为简化实体代码，我们将采用以下规则：实体的属性名称应与该实体需封装的 jSON 文件中的属性名称保持一致。 根据此规则，[Database, TaxAdminData, TaxPayerData] 类具有可归纳到父类中的共同点。该父类即为以下 [BaseEntity] 类：

    
<?php

namespace Application;

class BaseEntity {
  // 属性
  protected $arrayOfAttributes;

  // 从文件初始化jSON
  public function setFromJsonFile(string $jsonFilename) {
    // 从税务数据文件中读取内容
    $fileContents = \file_get_contents($jsonFilename);
    $erreur = FALSE;
    // 错误？
    if (!$fileContents) {
      // 记录错误
      $erreur = TRUE;
      $message = "Le fichier des données [$jsonFilename] n'existe pas";
    }
    if (!$erreur) {
      // 从配置文件中获取代码 jSON 并将其存入关联数组
      $this->arrayOfAttributes = \json_decode($fileContents, true);
      // 错误？
      if ($this->arrayOfAttributes === FALSE) {
        // 记录错误
        $erreur = TRUE;
        $message = "Le fichier de données jSON [$jsonFilename] n'a pu être exploité correctement";
      }
    }
    // 错误？
    if ($erreur) {
      // 抛出异常
      throw new ExceptionImpots($message);
    }
    // 初始化类属性
    foreach ($this->arrayOfAttributes as $key => $value) {
      $this->$key = $value;
    }
    // 返回对象
    return $this;
  }

  public function checkForAllAttributes() {
    // 验证所有键是否已初始化
    foreach (\array_keys($this->arrayOfAttributes) as $key) {
      if ($key !== "arrayOfAttributes" && !isset($this->$key)) {
        throw new ExceptionImpots("L'attribut [$key] de la classe "
          . get_class($this) . " n'a pas été initialisé");
      }
    }
  }

  public function setFromArrayOfAttributes(array $arrayOfAttributes) {
    // 初始化类的某些属性
    foreach ($arrayOfAttributes as $key => $value) {
      $this->$key = $value;
    }
    // 返回对象
    return $this;
  }

  // toString
  public function __toString() {
    // 对象的属性
    $arrayOfAttributes = \get_object_vars($this);
    // 移除父类的属性
    unset($arrayOfAttributes["arrayOfAttributes"]);
    // 对象的 JSON 字符串
    return \json_encode($arrayOfAttributes, JSON_UNESCAPED_UNICODE);
  }

  // getter
  public function getArrayOfAttributes() {
    return $this->arrayOfAttributes;
  }

}

    注释

    • 第 5 行：类 [BaseEntity] 旨在被类 [Database, TaxAdminData, TaxPayerData] 继承；
    • 第 7 行：属性 [$arrayOfAttributes] 是一个数组，包含所有继承自 [BaseEntity] 的子类的属性及其值；
    • 第 9-41 行：属性 [$arrayOfAttributes] 根据作为参数传递的文件 jSON [$jsonFilename] 进行初始化。 如果无法读取文件 jSON，或者该文件不是有效的 jSON 文件，则会抛出类型为 [ExceptionImpot] 的异常；
    • 第 36-38 行：此处为特殊代码，仅在由子类执行时生效。 在此情况下，[$this] 代表子类 [Database, TaxAdminData, TaxPayerData] 的实例，此时第 36-38 行将初始化该子类的属性，前提是这些属性具有 protected（或 public）的可见性（参见链接段落）。 实际上，我们曾提到 [Database, TaxAdminData, TaxPayerData] 实体的属性与它们所封装的 jSON 文件中的属性是相同的。 最后，[setFromJsonFile]方法允许子类基于jSON文件进行初始化；
    • 第40行：如果子类调用了方法[setFromJsonFile]，则返回对象[$this]，即子类的实例；
    • 第43-51行：方法[checkForAllAttributes]允许子类检查其所有属性是否已初始化。若未初始化，则抛出异常[ExceptionImpots]。 该方法允许子类验证其 jSON 文件是否遗漏了某些属性；
    • 第 53-60 行：方法 [setFromArrayOfAttributes] 允许子类根据一个关联数组初始化其全部或部分属性，该数组的键名与待初始化的子类属性名称相同；
    • 第 63-70 行：方法 [__toString] 允许获取子类的 jSON 表示形式；
