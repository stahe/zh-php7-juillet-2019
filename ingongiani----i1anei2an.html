    4. 应用练习——第1版和第2版

    4.1. 问题

    上表用于计算纳税人仅申报工资收入的简化情况下的税额。如注释（1）所示，由此计算出的税额是未考虑以下三项机制的税额：

    • 针对高收入群体的家庭商数上限；
    • 针对低收入群体的税额减免和减税；

    因此，税额计算包括以下步骤 [http://impotsurlerevenu.org/comprendre-le-calcul-de-l-impot/1217-calcul-de-l-impot-2019.php]：

    我们拟编写一个程序，用于计算纳税人的税额，具体针对仅需申报工资收入的简化情况：

    4.1.1. 应纳税额计算

    应纳税额可按以下方式计算：

    首先计算纳税人的份额数：

      • 每位父母计为1份；
      • 前两名子女各计1/2份；
      • 后续子女每人计1份：

    因此，份额总数为：

    • nbParts=1+nbEnfants*0.5+(子女数-2)*0.5（若雇员未婚）；
    • 若已婚，则nbParts=2+nbEnfants*0.5+(nbEnfants-2)*0.5；

    其中 nbEnfants 为其子女数；

    • 计算应税收入 R=0.9*S，其中 S 为年薪；
    • 计算家庭分摊系数 QF=R/nbParts；
    • 根据以下数据（2019年）计算应纳税额I：

    每行有 3 个字段：champ1、champ2、champ3。 要计算税款 I，需查找满足 QF<=字段1 的第一行，并取该行的数值。例如，对于一名已婚且有两个孩子的员工，年薪 S 为 50000 欧元：

    应税收入：R=0.9*S=45000

    份额数：nbParts=2+2*0.5=3

    家庭分额：QF=45000/3=15000

    满足 QF<=field1 的第一行如下：

        27519        0.14    1394.96

    因此，税额 I 等于 0.14*R – 1394.96*nbParts=[0,14*45000-1394,96*3]=2115。税额向下四舍五入至整欧元。

    若从第一行起即满足QF<=field1，则税额为零。

    若 QF 满足关系 QF<=field1 从未成立，则使用最后一行中的系数。此处：

        0            0.45        20163.45

    由此得出应纳税额 I=0.45*R – 20163.45*nbParts。

    4.1.2. 家庭商数上限

    要判断家庭商数上限 QF 是否适用，需重新计算不含子女的应纳税额。仍以已婚、育有两名子女且年薪 S 为 50000 欧元的雇员为例：

    应税收入：R=0.9*S=45000

    分额数：nbParts=2（不再计入子女）

    家庭分额：QF=45000/2=22500

    满足 QF<=field1 的第一行如下：

        27519        0.14    1394.96

    因此，税额 I 等于 0.14*R – 1394.96*nbParts=[0,14*45000-1394,96*2]=3510。

    与子女相关的最高收益：1551 * 2 = 3102 欧元

    最低税额：3510-3102 = 408 欧元

    已计算的含3个税额份额的应纳税额2115欧元高于最低税额408欧元，因此此处不适用家庭税额上限。

    一般而言，应纳税额为 (税款1 + 税款2)，其中：

    • [impôt1]：为包含子女计算的应纳税额；
    • [impôt2]：是不计入子女的应纳税额，并减去与子女相关的最高抵扣额（此处为每半份1551欧元）；

    4.1.3. 减免额的计算

    仍以那位已婚、育有两名子女且年薪S为50000欧元的雇员为例：

    上一步计算出的应纳税额（2115）低于已婚夫妇的2627欧元（单身人士为1595欧元）：因此适用减免。其计算方式如下：

    减免额 = 起征点（已婚夫妇=1970/单身=1196）-0.75 × 应纳税额

    减免额=1970-0.75*2115=383.75，四舍五入为384欧元。

    新应纳税额=2115-384=1731欧元

    4.1.4. 减税额计算

    当收入低于一定门槛时，对前文计算出的应纳税额给予20%的减免。2019年的门槛如下：

    • 单身：21037欧元；
    • 已婚夫妇：42074欧元；（上例中使用的37968这一数字似乎有误）；

    该门槛值需增加以下数值：3797 *（子女带来的半份数）。

    仍以那位已婚、育有两名子女且年薪S为50000欧元的雇员为例：

    • 其应税收入（45000欧元）低于门槛（42074+2*3797）=49668欧元；
    • 因此他有权享受20%的税额减免：1731 * 0.2 = 346.2欧元（四舍五入为347欧元）；
    • 纳税人的应纳税额为：1731-347=1384欧元；

    4.1.5. 净税额计算

    我们的计算到此为止：应缴净税额为1384欧元。实际上，纳税人还可以享受其他减免，特别是针对向公益或公共利益组织捐赠的减免。

    4.1.6. 高收入人群的情况

    前面的例子适用于大多数工薪阶层。然而，高收入群体的税款计算方式有所不同。

    4.1.6.1. 年度收入10%减免的上限

    在大多数情况下，应税收入按以下公式计算：R=0.9*S，其中S为年薪。这被称为10%的减免。该减免设有上限。2019年：

    • 减免额不得超过12502欧元；
    • 不得低于437欧元；

    以一名未婚且无子女、年薪为200000欧元的雇员为例：

    • 10%的减免额为200,000欧元 > 12,502欧元。因此，减免额被调整为12,502欧元；

    4.1.6.2. 家庭商数上限

    假设出现上文所述的家庭上限情况。以一对育有三个子女、年收入为100,000欧元的夫妇为例。重新梳理计算步骤：

    • 10%的免税额为10000欧元 < 12502欧元。因此应税收入R为100000-10000=90000欧元；
    • 该夫妇拥有nbParts=2+0.5×2+1=4个家庭份额；
    • 因此其家庭分额为 QF = R / nbParts = 90000 / 4 = 22500 欧元；
    • 其带子女的应纳税额I1为I1=0.14×90000-1394.96×4=7020欧元；
    • 其无子女的应纳税额I2：
      • QF=90000/2=45000欧元；
      • I2=0.3*90000-5798*2=15404欧元；
      • 家庭分额上限规则规定，子女带来的增益不得超过（1551×4个半份额）=6204欧元。但此处该数值为I2-I1=15404-7020=8384欧元，因此高于6204欧元；
      • 因此，应纳税额重新计算为 I3=I2-6204=15404-6204=9200欧元；

    这对夫妇既没有免税额，也没有减免，最终应缴税额为9200欧元。

    4.3.1. 算法

    我们在此展示一个初始程序，其中：

    • 计算税款所需的数据以数组和常量的形式硬编码在代码中；

function cutNewLinechar(string $ligne): string {
  // 如果存在，则删除 $ligne 中的行尾标记
  $L = strlen($ligne);  // 行长度
  while (substr($ligne, $L - 1, 1) === "\n" or substr($ligne, $L - 1, 1) === "\r") {
    $ligne = substr($ligne, 0, $L - 1);
    $L--;
  }
  // 结束
  return($ligne);
}

  // $marié：是，否
  // $enfants：子女人数
  // $salaire：年薪
  // $limites, $coeffR, $coeffN：用于计算税款的数据表

  $impot1 = $result1["impôt"];
  // 不含子女的税款计算
  if ($enfants != 0) {
    $result2 = calculImpot2($marié, 0, $salaire, $limites, $coeffR, $coeffN);
    $impot2 = $result2["impôt"];
    // 家庭商数上限的适用
    if ($enfants < 3) {
      // $PLAFOND_QF_DEMI_PART 欧元（前两名子女）
      $impot2 = $impot2 - $enfants * PLAFOND_QF_DEMI_PART;
    } else {

      $impot2 = $impot2 - 2 * PLAFOND_QF_DEMI_PART - ($enfants - 2) * 2 * PLAFOND_QF_DEMI_PART;

    $impot2 = $impot1;
    $result2 = $result1;
  }
  // 取税率最高的那项，并适用相应的税率和附加费
  if ($impot1 > $impot2) {
    $impot = $impot1;
    $taux = $result1["taux"];
    $surcôte = $result1["surcôte"];
  } else {
    $surcôte = $impot2 - $impot1 + $result2["surcôte"];
    $impot = $impot2;
    $taux = $result2["taux"];

  // 计算可能的减免额
  $décôte = getDecote($marié, $salaire, $impot);

  $réduction = getRéduction($marié, $salaire, $enfants, $impot);

  return ["impôt" => floor($impot), "surcôte" => $surcôte, "décôte" => $décôte, "réduction" => $réduction, "taux" => $taux];
}

    函数 [calculImpot2] 如下：

    
// --------------------------------------------------------------------------
function calculImpot2(string $marié, int $enfants, float $salaire, array $limites, array $coeffR, array $coeffN): array {
  // $marié：是，否
  // $enfants：子女人数
  // $salaire：年薪
  // $limites, $coeffR, $coeffN：用于计算税款的数据表
  //
  // 份额数
  $marié = strtolower($marié);
  if ($marié === "oui") {
    $nbParts = $enfants / 2 + 2;
  } else {
    $nbParts = $enfants / 2 + 1;
  }
  // 从第三个孩子起，每个孩子1个份额
  if ($enfants >= 3) {
    // 第3个及以后的每个孩子额外增加半份
    $nbParts += 0.5 * ($enfants - 2);
  }
  // 应税收入
  $revenuImposable = getRevenuImposable($salaire);
  // 附加费
  $surcôte = floor($revenuImposable - 0.9 * $salaire);
  // 用于四舍五入问题
  if ($surcôte < 0) {
    $surcôte = 0;
  }
  // 家庭分摊额
  $quotient = $revenuImposable / $nbParts;
  // 被放置在限额表的末尾，以终止后续循环
  $limites[count($limites) - 1] = $quotient;
  // 税额计算
  $i = 0;
  while ($quotient > $limites[$i]) {
    $i++;
  }
  // 由于将 $quotient 放置在 $limites 表的末尾，因此终止了前面的循环
  // 不能超出数组 $limites
  // 现在可以计算税款
  $impôt = floor($revenuImposable * $coeffR[$i] - $nbParts * $coeffN[$i]);
  // 结果
  return ["impôt" => $impôt, "surcôte" => $surcôte, "taux" => $coeffR[$i]];
}

// revenuImposable=年薪-扣除额
// 扣除额有最低值和最高值
function getRevenuImposable(float $salaire): float {
  // 工资的10%作为扣除额
  $abattement = 0.1 * $salaire;
  // 该扣除额不得超过 ABATTEMENT_DIXPOURCENT_MAX
  if ($abattement > ABATTEMENT_DIXPOURCENT_MAX) {
    $abattement = ABATTEMENT_DIXPOURCENT_MAX;
  }
  // 扣除额不得低于 ABATTEMENT_DIXPOURCENT_MIN
  if ($abattement < ABATTEMENT_DIXPOURCENT_MIN) {
    $abattement = ABATTEMENT_DIXPOURCENT_MIN;
  }
  // 应税收入
  $revenuImposable = $salaire - $abattement;
  // 结果
  return floor($revenuImposable);
}

define("PLAFOND_DECOTE_COUPLE", 1970);

// 计算可能的折价
function getDecote(string $marié, float $salaire, float $impots): float {
  // 初始折价为零
  $décôte = 0;
  // 享受减免的最高应纳税额
  $plafondImpôtPourDécôte = $marié === "oui" ? PLAFOND_IMPOT_COUPLE_POUR_DECOTE : PLAFOND_IMPOT_CELIBATAIRE_POUR_DECOTE;
  if ($impots < $plafondImpôtPourDécôte) {
    // 折扣上限
    $plafondDécôte = $marié === "oui" ? PLAFOND_DECOTE_COUPLE : PLAFOND_DECOTE_CELIBATAIRE;
    // 理论折扣
    $décôte = $plafondDécôte - 0.75 * $impots;
    // 折扣额不得超过应纳税额
    if ($décôte > $impots) {
      $décôte = $impots;
    }
    // 无折减 <0
    if ($décôte < 0) {
      $décôte = 0;
    }
  }
  // 结果
  return ceil($décôte);
}

    说明

    • 第6行：享有减免资格的应纳税额上限。该金额对单身人士和已婚夫妇有所不同；
    • 第7行：纳税人是否符合减免条件；
    • 第11行：减免额的计算公式。[plafondDécôte]为减免额上限。该上限金额在第9行计算得出。此处同样取决于纳税人的婚姻状况（已婚或单身）；
    • 第13-15行：减免额不得超过应缴税款总额。例如，当第11行中的[impots]等于0时即属此情况；
    • 第17-19行：为避免四舍五入至-1；

    函数 [getRéduction] 如下：

    
// 全局常量
define("PLAFOND_REVENUS_CELIBATAIRE_POUR_REDUCTION", 21037);
define("PLAFOND_REVENUS_COUPLE_POUR_REDUCTION", 42074);
define("VALEUR_REDUC_DEMI_PART", 3797);

    
// 计算可能的减免
function getRéduction(string $marié, float $salaire, int $enfants, float $impots): float {
  // 享有20%减免的收入上限
  $plafondRevenuPourRéduction = $marié === "oui" ? PLAFOND_REVENUS_COUPLE_POUR_REDUCTION : PLAFOND_REVENUS_CELIBATAIRE_POUR_REDUCTION;
  $plafondRevenuPourRéduction += $enfants * VALEUR_REDUC_DEMI_PART;
  if ($enfants > 2) {
    $plafondRevenuPourRéduction += ($enfants - 2) * VALEUR_REDUC_DEMI_PART;
  }
  // 应税收入
  $revenuImposable = getRevenuImposable($salaire);
  // 减免
  $réduction = 0;
  if ($revenuImposable < $plafondRevenuPourRéduction) {
    // 8折
    $réduction = 0.2 * $impots;
  }
  // 结果
  return ceil($réduction);
}

    说明

    • 第4-10行：要获得减税资格，应税收入（第10行）必须低于第4-8行计算出的上限；
    • 第13-16行：若符合条件，纳税人可享受20%的减税（第15行）；

function calculImpot(array $taxAdminData, string $marié, int $enfants, float $salaire) {
  // $marié：是，否
  // $enfants：子女人数
  // $salaire：年薪
  // $taxAdminData：税务部门数据
  //
  // 含子女的税额计算
  $result1 = calculImpot2($taxAdminData, $marié, $enfants, $salaire);
  $impot1 = $result1["impôt"];
  // 无子女的税款计算
  if ($enfants != 0) {
    $result2 = calculImpot2($taxAdminData, $marié, 0, $salaire);
    $impot2 = $result2["impôt"];
    // 家庭商数上限的适用
    if ($enfants < 3) {
      // $PLAFOND_QF_DEMI_PART 欧元（前两名子女）
      $impot2 = $impot2 - $enfants * $taxAdminData["PLAFOND_QF_DEMI_PART"];
    } else {
      // $PLAFOND_QF_DEMI_PART 欧元适用于前两名子女，后续子女金额加倍
      $impot2 = $impot2 - 2 * $taxAdminData["PLAFOND_QF_DEMI_PART"] - ($enfants - 2) * 2 * $taxAdminData["PLAFOND_QF_DEMI_PART"];
    }
  } else {
    $impot2 = $impot1;
    $result2 = $result1;
  }
  // 取税率最高的那项，并按其对应的税率和附加费计算
  if ($impot1 > $impot2) {
    $impot = $impot1;
    $taux = $result1["taux"];
    $surcôte = $result1["surcôte"];
  } else {
    $surcôte = $impot2 - $impot1 + $result2["surcôte"];
    $impot = $impot2;
    $taux = $result2["taux"];
  }
  // 计算可能的减免额
  $décôte = getDecote($taxAdminData, $marié, $salaire, $impot);
  $impot -= $décôte;
  // 计算可能的减税额
  $réduction = getRéduction($taxAdminData, $marié, $salaire, $enfants, $impot);
  $impot -= $réduction;
  // 结果
  return ["impôt" => floor($impot), "surcôte" => $surcôte, "décôte" => $décôte, "réduction" => $réduction, "taux" => $taux];
}

    • 版本 02 中的每个函数都必须使用数组 [$taxAdminData] 的内容；
    • 第83-126行： 在函数 [calculerImpot] 中，原先使用全局常量或数组 [limites, coeffR, coeffN] 的位置，现改用作为参数接收的数组 [$taxAdminData] 的内容（第 99、102 行）；

    4.4.2. 结论

    02版比01版灵活得多。2020年的税额计算算法很可能与2019年相同，仅税率区间和计算常量会发生变化。 届时只需更新文件 [taxadmindata.json] 即可。而在版本 01 中，则需要进入代码修改税率区间和计算常数。但需要修改税率区间和计算常数值的人员，很可能无法访问算法代码。
