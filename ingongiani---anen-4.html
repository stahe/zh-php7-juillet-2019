// 命名空间
namespace Application;

// 一个实用函数类
abstract class Utilitaires {

  public static function cutNewLinechar(string $ligne): string {
    // 如果存在，则删除 $ligne 的行尾标记
    $longueur = strlen($ligne);  // 行长度
    while (substr($ligne, $longueur - 1, 1) == "\n" or substr($ligne, $longueur - 1, 1) == "\r") {
      $ligne = substr($ligne, 0, $longueur - 1);
      $longueur--;
    }
    // 结束 - 返回该行
    return($ligne);
  }
}

    11.3. [dao] 层

    这里我们关注应用程序中的 [1] 层：

    11.3.1. [InterfaceDao] 接口

    [dao] 层的接口如下所示：[InterfaceDao.php]：

    
<?php

// 命名空间
namespace Application;

interface InterfaceDao {

  // 读取纳税人数据
  public function getTaxPayersData(string $taxPayersFilename, string $errorsFilename): array;

  // 读取税务机关数据（税率档次）
  public function getTaxAdminData(): TaxAdminData;

  // 结果记录
  public function saveResults(string $resultsFilename, array $taxPayersData): void;
}

    注释

    • 技术规范如下：
      • 纳税人的数据存储在文本文件中；
      • 将税款计算结果保存到文本文件中；
      • 将可能出现的错误记录到文本文件中；
      • 目前尚不清楚税务部门提供的数据以何种格式存在。对于每种新格式，都需要通过一个新类来实现 [InterfaceDao] 接口；
      • 接口中的方法在访问数据时若遇到不可恢复的错误，必须抛出类型为 [ExceptionImpots] 的异常；
    • 第 9 行：用于获取纳税人数据的 [statut marital, nombre d’enfants, salaire annuel] 方法；
      • 第一个参数是包含这些数据的文本文件名；
      • 第二个参数是用于记录可能遇到的错误的文本文件名；
    • 第12行：用于获取税务机关数据的方法。此处未传入任何参数，因为尚不清楚数据的存储格式；
    • 第15行：用于将税款计算结果保存到文本文件中的方法，该文件的名称作为参数传入；

    在编写接口 [InterfaceDao] 时，我们知道根据税务部门数据的存储方式不同，方法 [getTaxAdminData] 的实现方式也会有所不同。 因此，接口 [InterfaceDao] 将由不同的类来实现，每个类负责处理特定类型的数据存储（数组、文本文件、数据库、Web 服务）。不过，这些派生类将拥有共同的代码，即 [getTaxPayersData, saveResults] 方法的实现代码。 我们知道，该用例可通过两种方式实现（参见链接段落）：

    1. 创建一个抽象类 C，其中包含派生类共有的代码。类 C 实现了接口 I，但某些必须在派生类中声明的方法在类 C 中被声明为抽象方法，因此类 C 本身也是抽象类。 随后创建从 C 派生的类 C1 和 C2，它们各自以自己的方式实现父类 C 中未定义（抽象）的方法；
    2. 创建一个与前一解决方案中的抽象类 C 几乎完全相同的特质 T。该特质不实现接口 I，因为从语法上讲它无法实现。 随后创建类 C1 和 C2，它们实现接口 I 并使用特征 T。这些类只需实现特征 T 未实现的接口 I 中的方法即可；

    在此示例中，我们将使用一个名为 [TraitDao] 的特质。

    11.3.2. 特征 [TraitDao]

    [TraitDao] 特性的代码如下 [TraitDao.php]：

    
<?php

// 命名空间
namespace Application;

trait TraitDao {

  // 读取纳税人数据
  public function getTaxPayersData(string $taxPayersFilename, string $errorsFilename): array {
    // 纳税人数据表
    $taxPayersData = [];
    // 错误表
    $errors = [];
    // 只要处理文件，就可能会出现不少错误
    try {
      // 读取用户数据
      // 每行数据格式为：婚姻状况、子女数、年薪
      $taxPayersFile = fopen($taxPayersFilename, "r");
      if (!$taxPayersFile) {
        throw new ExceptionImpots("Impossible d'ouvrir en lecture les déclarations des contribuables [$taxPayersFilename]", 12);
      }
      // 处理用户数据文件中的当前行
      // 该行格式为：婚姻状况、子女数、年薪
      $num = 1;         // 当前行号
      $nbErreurs = 0;   // 遇到的错误数量
      while ($ligne = fgets($taxPayersFile, 100)) {
        // 忽略空行
        $ligne = trim($ligne);
        if (strlen($ligne) == 0) {
          // 下一行
          $num++;
          // 重新循环
          continue;
        }
        // 移除可能存在的换行符
        $ligne = Utilitaires::cutNewLineChar($ligne);
        // 提取组成 $ligne 的 3 个字段：已婚:子女:工资
        list($marié, $enfants, $salaire) = explode(",", $ligne);
        // 对其进行验证
        // 婚姻状况必须为“是”或“否”
        $marié = trim(strtolower($marié));
        $erreur = ($marié !== "oui" and $marié !== "non");
        if (!$erreur) {
          // 子女数量必须为整数
          $enfants = trim($enfants);
          if (!preg_match("/^\d+$/", $enfants)) {
            $erreur = TRUE;
          } else {
            $enfants = (int) $enfants;
          }
        }
        if (!$erreur) {
          // 工资为不包含欧元分数的整数
          $salaire = trim($salaire);
          if (!preg_match("/^\d+$/", $salaire)) {
            $erreur = TRUE;
          } else {
            $salaire = (int) $salaire;
          }
        }
        // 错误？
        if ($erreur) {
          $errors[] = "la ligne [$num] du fichier [$taxPayersFilename] est erronée";
          $nbErreurs++;
        } else {
          // 保存信息
          $taxPayersData[] = (new TaxPayerData())->setFromParameters($marié, $enfants, $salaire);
        }
        // 下一行
        $num++;
      }
      // 是否已到达文件末尾？
      if (!feof($taxPayersFile)) {
        // 因读取错误退出循环
        throw new ExceptionImpots("Erreur lors de la lecture de la ligne n° [$num] du fichier [$taxPayersFilename]");
      } else {
        // 因遇到文件结束标记而退出循环
        // 将错误保存到文本文件中
        $this->saveString($errorsFilename, implode("\n", $errors));
        // 函数结果
        return $taxPayersData;
      }
    } finally {
      // 若文件已打开则关闭
      if ($taxPayersFile) {
        fclose($taxPayersFile);
      }
    }
  }

  // 记录结果
  public function saveResults(string $resultsFilename, array $taxPayersData): void {
    // 将数组 [$taxPayersData] 保存到文本文件 [$resultsFileName] 中
    // 如果文本文件 [$resultsFileName] 不存在，则创建该文件
    $this->saveString($resultsFilename, implode("\n", $taxPayersData));
  }

  // 将表中的结果记录到文本文件中
  private function saveString(string $fileName, string $data): void {
    // 将表格 [$data] 保存到文本文件 [$fileName] 中
    // 如果文本文件 [$fileName] 不存在，则创建该文件
    if (file_put_contents($fileName, $data) === FALSE) {
      throw new ExceptionImpots("Erreur lors de l'enregistrement de données dans le fichier texte [$fileName]");
    }
  }

}

    注释

    • 第 6 行：此处定义的是一个特质，而非类；
    • 第 9-89 行：方法 [getTaxPayersData] 实现了接口 [InterfaceDao] 中同名的方法。 它从名为 [$taxPayersFilename] 的文本文件中提取纳税人 [statut marital, nombre d’enfants, salaire annuel] 的数据。 并将这些数据以 [$taxPayersData] 数组的形式返回，其中包含类型为 [TaxPayerData] 的元素（第 67、81 行）；
    • 方法 [getTaxPayersData] 与上文链接段落中描述的方法 [AbstractBaseImpots::executeBatchImpots] 非常相似，但存在以下区别：
      • 方法 [getTaxPayersData] 仅用于检索纳税人数据，不进行税额计算。此功能由层 [métier] 负责；
      • 与方法 [executeBatchImpots] 一样，它会报告错误。此处错误首先存储在数组 [$errors] 中（第 13 行），该数组在处理结束时会被保存到文本文件中（第 79 行）。根据具体情况，该数组可能为空，也可能不为空；
      • 若发生不可恢复的错误，将抛出类型为 [ExceptionImpots] 的异常（第 20、75 行）；
    • 第73行：请注意第26-71行循环结束时的处理逻辑。 实际上，函数 [fgets] 存在一个缺陷：无论行读取操作是遇到文件结束标记，还是因错误导致读取失败，它都会将布尔值 FALSE 设为真。 为区分这两种情况，我们使用函数 [feof] 检测是否已到达文件末尾。若未到达文件末尾，则说明发生了错误，此时将抛出异常；
    • 第83-88行：无论在处理文件时是否发生异常，都会执行[finally]；
    • 第 85 行：如果文件已被打开，则该文件的“句柄”[$taxPayersFile] 取布尔值 TRUE，否则取 FALSE；
    • 第99-105行：调用第79行中使用的私有方法[saveString]，将错误数组写入文本文件；
    • 第 99 行：方法 [saveString] 接收两个参数：
      • [string $filename]，即用于存储数据的文本文件名；
      • [string $data]，即要写入文本文件的字符串。该字符串将由多行组成，每行以换行符 \n 结尾；
    • 第 102 行：函数 PHP [file_puts_contents] 将字符串写入文本文件。 该函数负责打开文件、将字符串写入其中并关闭文件。若发生错误，则返回布尔值 FALSE；
    • 第 103 行：若发生错误，则抛出异常；
    • 第 92-96 行：实现接口 [InterfaceDao] 的方法 [saveResults]。再次使用了私有方法 [saveString]。 此处 [saveString] 的第二个参数是一个字符串，由数组 [$taxPayersData] 构建而成，该数组的元素类型为 [TaxPayerData]。人们可能会好奇该操作的结果会是什么： 
    
implode("\n", $taxPayersData)

    我们在类 [TaxPayerData]（链接段落）中定义了以下方法 [__toString]：

    
public function __toString() {
    // 对象的JSON字符串
    return \json_encode(\get_object_vars($this), JSON_UNESCAPED_UNICODE);
  }

    该操作

    
implode("\n", $taxPayersData)

    将把数组 [$taxPayersData] 的每个元素（通过其方法 [__toString] 转换为字符串）与换行符 \n 拼接起来。这将生成如下格式的字符串：

    json1\njson2\n…

    11.4. [métier] 层

    接下来我们将实现架构中的 [2] 层：

    11.4.1. [InterfaceMétier] 接口

    [métier] 层的接口如下：

    
<?php

// 命名空间
namespace Application;

interface InterfaceMetier {

  // 计算纳税人的税款
  public function calculerImpot(string $marié, int $enfants, int $salaire): array;

  // 批处理模式下的税款计算
  public function executeBatchImpots(string $taxPayersFileName, string $resultsFileName, string $errorsFileName): void;
}

    注释

    • 第 9 行：[InterfaceMétier] 接口能够计算特定纳税人的税额，前提是提供以下信息：婚姻状况、子女数量、年薪。 方法 [calculerImpot] 不使用 [dao] 层，因此不会抛出异常；
    • 第 9 行：接口 [InterfaceMétier] 还可以计算一组纳税人的税额，这些纳税人的数据汇总在名为 [$taxPayersFileName] 的文本文件中。它将结果写入名为 [$resultsFileName] 的文本文件中。 方法 [executeBatchImpots] 必须调用负责文件系统访问的 [dao] 层。 此时，[dao]层可能会抛出异常，而方法[executeBatchImpots]不会捕获这些异常：它将允许异常向上传递至主脚本。非致命错误将记录在名为[$errorsFileName]的文本文件中；
    • 第 9 行：方法 [calculerImpot] 是一个纯粹的 [métier] 方法。它不关心所用数据的来源；
    • 第 12 行：方法 [executeBatchImpots] 将调用底层 [dao] 进行文本文件的读写操作。它将反复调用业务方法 [calculerImpot]；

    方法 [calculerImpots] 如下：

    
public function calculerImpot(string $marié, int $enfants, int $salaire): array {
    // $marié：是，否
    // $enfants：子女数量
    // $salaire：年薪
    // $this->taxAdminData：税务部门数据
    //
    // 验证是否已获取税务部门数据
    if ($this->taxAdminData === NULL) {
      $this->taxAdminData = $this->getTaxAdminData();
    }
    // 计算含子女的税额
    $result1 = $this->calculerImpot2($marié, $enfants, $salaire);
    $impot1 = $result1["impôt"];
    // 计算不含子女的税额
    if ($enfants != 0) {
      $result2 = $this->calculerImpot2($marié, 0, $salaire);
      $impot2 = $result2["impôt"];
      // 应用家庭商数上限
      $plafonDemiPart = $this->taxAdminData->getPlafondQfDemiPart();
      if ($enfants < 3) {
        // $PLAFOND_QF_DEMI_PART 欧元（前两名子女）
        $impot2 = $impot2 - $enfants * $plafonDemiPart;
      } else {
        // $PLAFOND_QF_DEMI_PART 欧元（前两名子女），后续子女金额翻倍
        $impot2 = $impot2 - 2 * $plafonDemiPart - ($enfants - 2) * 2 * $plafonDemiPart;
      }
    } else {
      $impot2 = $impot1;
      $result2 = $result1;
    }
    // 取最高税率
    if ($impot1 > $impot2) {
      $impot = $impot1;
      $taux = $result1["taux"];
      $surcôte = $result1["surcôte"];
    } else {
      $surcôte = $impot2 - $impot1 + $result2["surcôte"];
      $impot = $impot2;
      $taux = $result2["taux"];
    }
    // 计算可能的减免额
    $décôte = $this->getDecôte($marié, $salaire, $impot);
    $impot -= $décôte;
    // 计算可能的减税额
    $réduction = $this->getRéduction($marié, $salaire, $enfants, $impot);
    $impot -= $réduction;
    // 结果
    return ["impôt" => floor($impot), "surcôte" => $surcôte, "décôte" => $décôte, "réduction" => $réduction, "taux" => $taux];
  }

    注释

    • 此代码属于第 3 版中的 [AbstractBaseImpots::calculerImpot] 方法，具体说明见链接段落。私有方法 [calculerImpot2, getDecôte, getRéduction, getRevenuImposable] 也是如此；

    方法 [Metier::executeBatchImpots] 如下：

    
public function executeBatchImpots(string $taxPayersFileName, string $resultsFileName, string $errorsFileName): void {
    // 上报来自 [dao] 层的异常
    // 获取纳税人数据
    $taxPayersData = $this->dao->getTaxPayersData($taxPayersFileName, $errorsFileName);
    // 结果表
    $results = [];
    // 对结果进行分析
    foreach ($taxPayersData as $taxPayerData) {
      // 计算税款
      $result = $this->calculerImpot(
        $taxPayerData->getMarié(),
        $taxPayerData->getEnfants(),
        $taxPayerData->getSalaire());
      // 填写[$taxPayerData]
      $taxPayerData->setMontant($result["impôt"]);
      $taxPayerData->setDécôte($result["décôte"]);
      $taxPayerData->setSurCôte($result["surcôte"]);
      $taxPayerData->setTaux($result["taux"]);
      $taxPayerData->setRéduction($result["réduction"]);
      // 将结果填入结果表
      $results [] = $taxPayerData;
    }
    // 保存结果
    $this->dao->saveResults($resultsFileName, $results);
  }

    注释

    • 第 1 行：该方法必须针对文本文件 [$taxPayersFileName] 中找到的每个纳税人，反复调用方法 [calculerImpot]。并将结果写入名为 [$resultsFileName] 的文本文件中。 遇到的非致命错误将记录在名为 [$errorsFileName] 的文本文件中。该方法本身不会抛出异常，但会将 [dao] 层抛出的异常向上传递；
    • 第 4 行：向 [dao] 层请求纳税人数据。该层返回一个 [TaxPayerData] 类型的数组，该类型是 [marié, nbEnfants, salaire, montant, décôte, réduction, surcôte, taux] 属性类的实例（参见链接段落）。 如果此处发生异常，由于未被 catch 捕获，异常将自动回传至调用代码。这意味着一旦发生异常，第 6 行将不会执行；
    • 第 6 行：类型为 [TaxPayerData] 的结果数组；
    • 第 8-22 行：计算纳税人数组 [$taxPayersData] 中每个元素的税额。为此，调用内部方法 [calculerImpot]（第 10 行）；
    • 第15-19行：利用所得结果初始化[TaxPayerData]表中尚未初始化的属性；
    • 第21行：将所得结果累加到结果表[$results]中；
    • 第24行：在为所有纳税人计算完税款后，结果被保存到文本文件中。这项工作由[dao]层负责；

    11.7. 测试 [Codeception]

    视觉测试非常不充分：

    • 通常仅进行少量测试；
    • 在进行目视检查时，注意力或多或少会有所疏忽，导致细节可能被遗漏；

    在实际的职业开发中，测试由专门负责此项工作的测试人员编写，这是他们的主要职责。因此，他们会力求使测试尽可能全面。为此，他们会使用测试框架。
